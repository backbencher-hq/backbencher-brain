# Web/Data/Query/Config/Shell Fixture Limitations (16 languages)

This fixture validates declaration extraction for the web, data, query, config,
and shell languages through the shared indexing pipeline. The symbol truth is
manually audited from the fixture source and stored in
`validation/m11/ground-truth/web-symbols.json`; the observed result is
generated by `script/gen-web-observed.ts` and compared by
`validation/m11/probe-web.ts`.

All 16 languages resolve at **1.000 precision / 1.000 recall** against ground
truth (295/295 symbols).

## Languages covered

Tier 1: SQL, XML, Bash, HTML, CSS.
Tier 2: GraphQL, YAML, JSON, PHP, Perl, R, Lua, HCL, PowerShell, Make,
Markdown.

## Universal contract mapping (M11.12)

- **SQL**: `CREATE TABLE` → `class`; column definitions → `property`; `CREATE
  INDEX` → `constant`. Anonymous `SELECT`s are statements, not symbols.
- **XML**: element tags → `class`; attributes → `property`; element containment
  via the parent chain (self-closing and text-only elements included).
- **HTML**: only elements carrying an explicit `id` or `class` become `class`
  symbols, named by the id first then the class. Anonymous structural tags
  (`<div>`, `<head>`, …) are intentionally not symbols.
- **CSS**: selectors → `class`/`type`/`interface` by specificity composition;
  custom properties (`--var`) → `variable`; `@keyframes` names → `function`.
  Universal reset rules (`*, *::before, *::after`) and `@media` queries are
  structural noise, not symbols.
- **GraphQL**: `type`/`interface`/`input`/`enum`/`scalar` declarations →
  `class`; fields and enum values → `property`.
- **YAML**: the document module is named after the file stem; mapping keys →
  `property`; sequence elements are not standalone symbols (their inner keys
  chain to the parent key), mirroring the JSON array contract.
- **HCL**: `variable`/`output` blocks → `variable` named by label;
  `resource`/`data` blocks → `class` named `type_instance`; `module`/`provider`/
  `terraform`/`locals` blocks → `module`; attributes → `property`.
- **Bash**: function definitions → `function`; `local`/`readonly` assignments →
  `variable`. Command invocations inside `case` branches are calls, not
  declarations.
- **PowerShell**: functions → `function`; classes → `class` with `constructor`
  and `method` members. `param(...)`/scriptblock locals are not symbols.
- **PHP**: namespace → `namespace`; classes → `class`; methods → `method`;
  class constants → `constant`; properties → `property`; functions →
  `function`; local assignments → `variable`.
- **Perl**: `package` → `class`; Moose `has` attributes → `property`;
  subroutine declarations inside a package → `method`; all-caps `our`
  declarations (e.g. `$VERSION`) → `constant`. Anonymous subroutine
  expressions (closure defaults) are expressions, not symbols.
- **Lua**: `local` assignments → `variable`; table-prefixed function
  definitions (`Order.new`, `Order:add_item`) → `method`. Field mutations
  (`Order.__index = Order`) and reassignments of locals (`sum = sum + …`) are
  not re-declared.
- **R**: named function assignments → `function`; all-caps assignments →
  `constant`; `R6::R6Class` → `class` with its `public`/`private`/`active`
  members → `method`; S3 methods (`summary.OrderBook`) → `method`; other
  assignments → `variable`. Field mutations (`self$orders <- …`) and anonymous
  function expressions are not symbols.
- **JSON**: document root → `module` named after the file stem; object-valued
  pairs → `class`; scalar pairs → `property`; array-valued pairs → `variable`.
  Anonymous object/array nodes are not symbols.
- **Markdown**: ATX headings → `type` (hierarchy via parent chain). Inline
  links/code spans are not yet symbols.
- **Make**: variable assignments → `constant`; explicit rule targets →
  `function` (variable targets such as `$(APP)` kept verbatim). `.PHONY` and
  `include` are meta-directives, not symbols.

## Coverage gaps

- **SQL** (partial): the bundled tree-sitter-sql grammar does not parse
  `CREATE VIEW` / `CREATE PROCEDURE` / `CREATE FUNCTION` bodies; the fixture is
  scoped to the grammar-supported subset (tables, columns, indexes, SELECTs).
  Ad-hoc anonymous `SELECT`s are intentionally not emitted as symbols. Real-
  corpus evidence now exists via ProxiCall's 185 committed SQL files (1,556
  symbols; PL/pgSQL function/trigger bodies extract 0 symbols — grammar-caused
  and documented above). An independent SQL acquisition remains a planned
  follow-up in `corpus-manifest.json`.
- **GraphQL** (partial): only two standalone `.graphql` files exist in
  graphql-js; this validates schema extraction against the largest public
  schema but not broad multi-schema application coverage. Query/operation
  files produce no symbols by design.
- **XML** (partial): measured across phpunit + powershell (271 real files,
  3,788 symbols); a dedicated standalone XML configuration corpus remains a
  planned acquisition.
- **HTML**: only id/class-identified elements are symbols; anonymous
  structural markup (most real-world templates) contributes relationships but
  not symbols. A larger HTML application corpus is not yet measured.
- **CSS**: `@media`/`@supports` queries and universal reset rules are scoped
  noise; `@keyframes` is the only at-rule emitted as a symbol.
- **HCL**: tree-sitter-hcl flattens object-valued attributes
  (`aws = { source = ... }`) into unparsed `expression` nodes, so inner keys of
  object bodies are not extractable via the AST (documented, grammar-caused).
- **Markdown**: only ATX headings are extracted; setext headings, definition
  lists, and inline links are not yet symbols.
- **YAML**: sequence elements (array items) are not standalone symbols; their
  keys chain to the parent key. This mirrors the JSON array contract but means
  per-item identity is not captured.
- **Make**: only 3 real Makefiles across the evidence repos (luarocks +
  terraform → 53 symbols); `$(VAR)` targets are emitted verbatim. Make evidence
  is fixture + ubiquitous-file based; a dedicated Make corpus is a planned
  acquisition.
- **Lua**: table-constructor "classes" are represented by their assignment
  variable + `method` members rather than a separate class symbol; the fixture
  reflects that contract.

- **Bash** (partial): only 34 real `.sh` files across the evidence repos
  (terraform + powershell + luarocks → 460 symbols); the fixture remains the
  primary declaration evidence for shell scripting constructs.
- **Markdown**: real corpus files yield few symbols by design (headings only);
  the fixture documents the extraction contract.
- **JSON** (partial): real corpus files are configuration/metadata bundles, so
  the fixture (nested objects, arrays, scalar types) remains the declaration
  evidence.
