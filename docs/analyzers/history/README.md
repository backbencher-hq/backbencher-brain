# Analyzer lane journals (historical)

These are the pre-consolidation verdict and investigation journals that used to sit beside the analyzer
documentation as `docs/analyzers/<language>.md`. Since 2026-11-01 there is exactly **one canonical page per
analyzer** at [`../<language>.md`](../README.md) — the page the documentation gate measures — and the journals
live here, out of the canonical set but still resolvable, because tracked analyzer code, spec files and
`validation/` evidence cite them by path.

They are evidence of how a lane reached its current state (rounds, falsifiers, pre-registrations and the
numbers that moved), not statements of current behaviour. Prefer the canonical page for a contract; come here
when you need the measurement history behind a claim.
