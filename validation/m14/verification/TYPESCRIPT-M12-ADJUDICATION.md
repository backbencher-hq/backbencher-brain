# TYPESCRIPT — M12 DIFFERENTIAL ADJUDICATION (2026-11-18)

The lane's completion does not depend on M12 (the owner's six conditions are implemented /
whole-population / resolved / walls-dispositioned / fixtures / no-regex), but a red differential
that is never explained reads as an unexplained defect. This page closes that: **every one of the
canonical artifact's 65 false positives and 6 false negatives is assigned to a NAMED cause, and the
current scoped differential's residue is classified row-for-row with bucket counts that close
exactly.** Nothing on this page is inferred from a doc: every number is a re-measurement at the
revision named beside it.

The residue is dominated by ONE class: the **uses/references boundary**, because the tree-truth
oracle derives both labels from the tree and the analyzer applies the lane's one-label ruling
(`references` = a mention of a type; `uses` = a value/member read in expression position; the
2026-10-17 narrowing per position). That is a *decision*, not an unexplained defect — but a decision
must be priced, so the row-level classifier was run.
