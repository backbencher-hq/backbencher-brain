groovy: the lane reads 11/11 — the spec, the verdict page, and the writer that keeps them true

THE COVERAGE-BLOCK GATE READS THIS LANE CLEAN AT 11/11: `groovy yes 11 11 3 - -`,
and `blocks with problems 0`. The eleven are the ten canonical types plus
`decorates`; the three exclusions are `renders`, `part_of` and `mixes_in`, and
each one carries a CLASS, a COUNT and a CITATION to a file that exists.

THE THREE RULINGS, and what each one is a ruling ABOUT:

`mixes_in` — ONTOLOGICAL, and it is a GROOVY question, not a lazy one. Groovy
HAS traits (169 trait declarations over the admitted population) and a trait is
applied in exactly two ways, both already published: through `implements` and
through `extends`. There is no third form, and the parse tree is why — a trait
application is an ordinary `super_interfaces` -> `type_list` -> `type_identifier`
entry with no grammar-level distinction from an interface. And the tie-break that
makes this a ruling rather than a preference is the enum's OWN contract:
`mixes_in` exists because in Dart a mixin is neither `extends` nor `implements`
("no conformance is declared"), and in Groovy the conformance IS declared, so the
`implements` edge is the truthful one. A construct that is expressible in the
same way as an already-implemented type is not a new type — it is that type,
spelled differently.

`renders` — ONTOLOGICAL, with the near miss counted in two halves: the OTHER
DIALECT's dialect (683 Grails `.gsp` templates in grails-core DO render
components, and the M60 #913 ruling stopped routing them to groovy because the
Groovy grammar has no productions for them) and the IN-LANGUAGE nearest
neighbour (the GString `template_expression` nodes, which render a VALUE, not a
component).

`part_of` — GRAMMAR-ABSENCE: the served build's 163 named node types name 0 of
them with a `part` shape, and the `part` / `part of` token shapes are counted
as the near miss.

A type in GRAMMAR REMEDY PENDING stays in the denominator, so this lane has NO
pending type: every type in its denominator is implemented, and the three types
outside it are there because the language does not express them.
