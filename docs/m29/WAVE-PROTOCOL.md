# The wave protocol — onboarding language N+1 (M29.R1)

Generated by `script/m29/generate-wave-doc.ts` from the live protocol
module (`script/m29/wave-protocol.ts`). Hand edits fail the drift gate
(`script/m29/verify-wave-protocol.ts`); regenerate, never hand-edit.

The protocol is the contract §9 extension rule made mechanical: a
candidate language walks a fixed checklist, and its IDE claim level is
**capped by what machine evidence proves** — the cap is computed, not
chosen. Adding language N+1 is a routine gated wave, never a redesign.

## The binding

```
I0  default. Unverified. Nothing ships behind a trust label.
I1  protocol-passed   := S1 ^ S2 ^ S3 ^ S4        (cap: I1-floor rules in code)
I2  index-conformant  := I1 ^ S5                   (worked: I2)
I3  editor-verified   := I2 ^ S6                   (worked: I3)
```

Any FAILED step caps the language below the tier containing it — a
failed gate is never climbed past. A BLOCKED step records its machine
reason in `blockers[]`; silence is guilt (contract §8.3).

## The checklist

| Step | Tier | What it proves | Evidence |
| --- | --- | --- | --- |
| S1 `S1-analyzer-conformance` | I0 -> I1 | the analyzer holds #419 CONFORMANT: every section in the committed SPEC ledger (validation/m14/results/M14.0.SPEC.json) reads pass, mechanically — a language absent from the ledger is declared absent, never assumed | the SPEC ledger at HEAD (machine-read, not re-run) |
| S2 `S2-position-gate` | I0 -> I1 | the position-mapping gate (script/m24/verify-positions.ts) exits 0 at HEAD — contract §5, the CC1 bug class | spawned exit code, recorded per run |
| S3 `S3-freshness-gate` | I0 -> I1 | the freshness gate (script/m24/verify-freshness.ts) exits 0 at HEAD — contract §4 | spawned exit code, recorded per run |
| S4 `S4-real-index` | I0 -> I1 | a per-language fixture pack (script/m29/wave-fixtures/<lang>/) is indexed by the REAL compiled indexer (dist/index.js indexProjectParallel) into a real brain.db; an empty index is a fail, a missing pack a blocked reason | file/symbol/relationship counts from the real index |
| S5 `S5-server-leg` | I1 -> I2 | the real bb_lsp server is driven over stdio against the language's OWN index with per-language feature assertions (hover, definition, references, symbols) — R2's execution leg | per-language server-leg evidence JSON |
| S6 `S6-editor-leg` | I2 -> I3 | an in-editor run (E5 pattern) exercises the language end to end; the runner honors RECORDED evidence (validation/m29/results/wave-editor-<lang>.json) and never assumes it | wave-editor-<lang>.json with editor version, OS, commit |

## Runner

```bash
npx tsx script/m29/wave-protocol.ts --language <lang> --out validation/m29/results/wave-<lang>.json
```

Registry (21 candidates): java, groovy, kotlin, scala, typescript, javascript, vue, svelte, go, rust, python, csharp, dart, ruby, php, c, cpp, zig, haskell, objc, swift.
Exit 0 = every non-blocked step passed; exit 1 = any real failure; exit
2 = usage error. The verdict JSON lists every step's status and detail,
the computed cap, and the blockers.

## Mutation rules (what the verifier must catch)

- a failing SPEC section must drop the cap below I1 — cap stays I0 when S1 fails.
- a language absent from the ledger must be declared absent — S1 returns conformant=false with the reason.
- a failed component gate must cap below I1 — cap stays I0 when S2/S3 fail.
- a blocked S4 must never read as pass — cap stays I0; blocker recorded.
- a skipped server leg must cap below I2 — cap stays I1 when S5 is blocked.
- assumed editor evidence must be rejected — cap stays I2 without recorded S6 evidence.

## Fixture packs (R2)

A wave pack lives at `script/m29/wave-fixtures/<lang>/main.<ext>` and is
authored adversarially: declarations, inheritance, calls, imports,
cross-file references, and at least one case the language is known to
get wrong without care (arrays, casts, patterns). The pack is indexed
for real; the counts land in the verdict. Per-language feature
assertions (S5) and in-editor evidence (S6) are R2 execution work and
are honored from recorded evidence only.
