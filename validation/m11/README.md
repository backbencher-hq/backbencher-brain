# M11 Validation Evidence

This directory is version-controlled product validation evidence.

The only content permitted outside the repository is cloned source code under
`/home/ishaq2321/bb_tests/repositories`. Manifests, pinned revisions, expected
facts, minimized fixtures, raw and normalized results, benchmarks, audits, and
harnesses belong here.

`corpus-manifest.json` is the current inventory. A repository is
`evidenceEligible` only when its checkout is clean and its revision is pinned.
Dirty home-directory worktrees remain exploratory inputs and must not be used
as final correctness evidence.

The reusable differential harness is in `script/m11/differential-harness.ts`.
Ground truth, observed facts, and run results use the machine-readable schemas
under `validation/m11/schemas`. Expected facts must come from source,
compiler, language-service, IDE-index, or manual-audit authority and must not
be generated by the analyzer being measured.
