# M14 results archive — measurement records, not evidence claims

This directory holds the `validation/m14/results/*.json` files that are **measurements with no live
consumer**. They were moved here **unchanged** (`git mv`, no edit to any file's bytes — the sha256
prefix in each row lets any reader check that against the bytes they are reading).

The results directory has two legitimate kinds of file, and this README names both:

1. **Claims** — schemaVersion-2 evidence artifacts, written only by `emitEvidence` in
   `script/m14/evidence-harness.ts`: an `issueId` matching `/^M14\./`, a `claimLevel` from the
   L0–L5 enum, a non-empty `checks[]`, a `limitations[]`, and the banned-vocabulary lint over the
   claim fields. Regeneration at the same HEAD is byte-identical, so a re-run is the drift check.
2. **Measurement records** — payloads of counts, rows and per-corpus samples that lane declarations,
   lanes' gates and docs quote. They carry no claim envelope (no `issueId`, `claimLevel`,
   `checks[]`, `limitations[]`), so they cannot pass as claims. Two honest placements exist:
   - a record with a **live consumer** (a script reads or writes it at its canonical path) stays in
     `results/` and is a **NAMED registration** in the harness's `MEASUREMENT_RECORDS` allowlist —
     validated as parseable JSON only, printed by name in `validate` output, never treated as a
     claim. Section A below lists all ten with their consumer; the authoritative list is the exported
     `MEASUREMENT_RECORDS` map in `script/m14/evidence-harness.ts`.
   - a record with **no consumer anywhere** is frozen here, byte-unchanged. Section B below lists all
     83, each with its date and why it is a measurement.

This is not a loosening of the gate. Before this cleanup the gate printed `54/147 evidence files
valid` and exited 3: 93 files had never passed. After it, every remaining file is accounted for and
`validate` exits 0 with `N/N evidence files valid` — 67/67 at the time of the cleanup (57
schemaVersion-2 claim artifacts generated by the campaign's gates + the 10 registered measurement
records listed below; the gate's own run is the authority for N). Nothing that passed was moved, no
file's bytes were edited, and no claim was fabricated over a measurement.
