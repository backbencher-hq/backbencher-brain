# LANGUAGE MATRIX — EXTENDED (14 emitted relationship values × 50 lanes)

**Regenerated 2026-11-22 by the Lead, over ALL 50 lanes.** This is the closure
matrix: every lane's every relationship type is either implemented (E, E·U) or ruled out of
the denominator (X, Z). A lane with a `P`, `z`, or `·` cell is not closed.

Generated by `bun script/m14/extended-matrix.ts`, which VERIFIES ITSELF against the arbiter:
it runs `script/m14/coverage-block-gate.ts`, reads the gate's own per-lane columns, and compares
them with what it computed. A disagreement is a failure, because a matrix that contradicts the
arbiter is worse than no matrix.

**THIS IS THE FLEET CLOSURE MATRIX.** Every one of the 50 lanes is scored over the full
fourteen-value vocabulary: each cell is implemented (E / E·U) or ruled (X / Z). The former
ten-value resolution census measured a different question and is retired as a completion
artifact; its 172/423 figure is not a completion measure. Each lane's own applicable
denominator is beside it, and a `P` / `z` / `·` cell is a real gap.

## THE LEGEND, AND WHY EACH MARK IS A DIFFERENT CLAIM

| mark | claim | what it costs |
|---|---|---|
| **E** | IMPLEMENTED — the analyzer emits the type and the corpus exercises it | in the denominator, satisfied |
| **E·U** | IMPLEMENTED AND CORPUS-UNEXERCISED — the analyzer emits the type and the corpus does not exercise it | in the denominator, satisfied; the fixture is the evidence |
| **P** | GRAMMAR REMEDY PENDING — work in flight, a rung is available | IN the denominator, counted as an UNIMPLEMENTED GAP |
| **X** | RULED — the grammar's own inventory has no such construct, or the type is ruled out of the language's expressible set | OUT of the denominator |
| **Z** | RULED zero-emission fact — the analyzer never emits it AND the grammar has no such construct | OUT of the denominator |
| **z** | RULED zero-sites — the analyzer never emits it, but the type is still IN the denominator | IN the denominator, counted as a gap |
| **·** | A GAP — expressible, not implemented, not ruled | IN the denominator, counted as a gap |

**THE PENDING MARK IS THE ONE THAT MATTERS MOST.** A type in GRAMMAR REMEDY PENDING STAYS IN THE
DENOMINATOR, counted as an unimplemented gap. The denominator is the language's own expressible
set, and a pending type IS expressible — that is exactly why a rung is available. The deciding
argument is the incentive: if pending left the denominator, a lane could improve its own ratio by
DECLARING work in flight instead of DOING it, which is the julia-lane failure the gate was written
to prevent. So a lane with work in flight reads SHORT, and its number cannot improve by
reclassifying. The DONE condition is separate from the ratio and is unchanged.

## 4 · WHAT THIS TABLE SAYS, AND WHAT IT DOES NOT

THE ROW IS NOT THE FLEET'S SCORE. The denominator differs per lane by construction, so the
**ratio** is a per-lane claim about a per-lane expressible set, and the fleet row above is a sum
over 50 different denominators — a bookkeeping total, NOT a single measure of the fleet. The
owner's bar is per language: each language's own expressible set, n/n, measured on the whole
admitted population, correctly resolved, every wall dispositioned with a count and a falsifier.

THE TABLE IS A DECLARATION SURFACE, NOT A MEASUREMENT. It says what each lane CLAIMS. The
measurement is each lane's own whole-population arm, and the arbiter is
`script/m14/coverage-block-gate.ts` — which reads the spec files directly, recomputes every
denominator, checks every ruling for a class and a count and a citation to a file that EXISTS,
and compares the lane's declared n against its own computed one.

THE SOURCE OF EVERY MARK IS `script/m14/spec/<lane>-completeness.json`, and the reading rules are
the GATE'S OWN: `applicable = 14 − grammar-absence-and-ruling-classes − zeroEmissionFacts`
(`script/m14/coverage-block-gate.ts:864-866`), the four ruling classes at `:92` and `:676`, and the
class normalisation (the LEADING TOKEN, so a class with a parenthetical gloss is its leading
token) at `:657`. A matrix that used a different class set would report denominators the gate
cannot reproduce, which is the defect the gate's own denominator cross-check exists to catch.
